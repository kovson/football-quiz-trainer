# Publish daily training sessions on GitHub Pages

Daily training sessions will be published as static material on GitHub Pages using GitHub Actions. This matches the team's chosen hosting approach and gives every teammate the same material without an application server generating questions during practice. Question authoring runs locally through Codex; GitHub receives the generated content and does not store an AI API key.

The site will be publicly accessible and shared with friends by URL. Private access and a central personal-progress store are outside the first version; the current browser saves a member's place for pause-and-continue practice.
